# ODbL 재배포 조건 점검 (사람용 요약)

상세 원문 인용: [docs/agent/odbl-review.md](../agent/odbl-review.md) · 작성 2026-11-05 · **법률 판단이 아니다. 최종 확인은 법률 자문으로 한다.**

## 1. 팩 구성요소별 판단 (우리 해석 초안)
| 파일 | 정의상 분류 | 근거 |
| --- | --- | --- |
| `graph/korea.graph.bin` (경로 그래프) | 파생 데이터베이스 가능성 높음 | OSM 데이터를 가공해 새 DB로 만듦 (1.0 정의) |
| `poi/korea.poi.sqlite` (POI 검색 DB) | 파생 데이터베이스 가능성 높음 | OSM 태그를 추출해 새 DB로 만듦 |
| `map/korea.mbtiles` (벡터 타일) | **판단 보류** | 원문에 벡터 타일 분류 문장 없음(H항). 보수적으로 파생 DB로 보는 것이 안전 |
| 앱 화면(지도 렌더, 검색 결과) | 제작물(Produced Work) | 출처 표기만 필요 (4.3) |

## 2. 배포 방식별 결과
- **공개 URL로 팩 다운로드 제공 (GitHub 공개 릴리스, R2 퍼블릭 버킷 등):** 공개 사용(Publicly Use)에 해당한다. 파생 DB를 **ODbL로** 제공해야 하고(4.4 a), 기계 판독 가능한 전체 DB 또는 변경 파일을 **인터넷으로 무료 제공**해야 한다(4.6). ODbL 사본 또는 URI도 함께 둬야 한다(4.2 b).
- **앱스토어 배포로 팩을 앱에 포함:** 공개 배포로 볼 가능성이 크다. 같은 의무가 따른다.
- **내부 사용만 (조직 내부, 비공개 테스트):** 공개 사용이 아니므로 동일 조건 공개 의무가 없다(4.5 c).

## 3. 항상 필요한 것 (공개 사용 시)
- 출처 표기: "OpenStreetMap" 링크 + ODbL 링크 (OSM 가이드). 현재 앱은 "© OpenStreetMap contributors" 문구만 있고 ODbL 링크는 없다.
- 제작물에 표기가 보이도록 할 것 (4.3). 홈 화면과 지도 스타일에 문구가 있다.

## 4. 사용자가 정해야 할 것
1. **팩을 공개로 배포할지:** 공개하면 4.4·4.6 의무를 지켜야 한다. 공개하지 않으면 팩 다운로드 기능은 내부 테스트용으로만 쓴다.
2. **벡터 타일(mbtiles)을 파생 DB로 볼지:** 법률 자문에서 확인한다. 보수적으로는 파생 DB로 보고 같이 공개한다.
3. **법률 자문 의뢰:** 위 1·2항과 "공개 배포 여부"를 질문지로 정리해 전달한다.

## 5. 확인하지 못한 것
- 제작물 가이드라인, 실질적 부분(Substantial) 기준, 벡터 타일 관련 OSMF 문서는 이번 점검에서 읽지 않았다.

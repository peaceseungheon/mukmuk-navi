# 묵묵 배포 준비 — 사용자 할 일

상세: `docs/agent/release.md` (2026-11-04 2차 점검)

## 사용자 할 일 (USER)

1. 릴리스 권한 결정: 릴리스 APK에 `INTERNET`·`ACCESS_NETWORK_STATE`·`ACCESS_WIFI_STATE`가 들어 있다(플러그인이 추가). 오프라인 앱에 필요 없으면 제거하도록 지시. 제거 시 실기기 확인 필요.
2. 릴리스 번호 정책 정하기 (현재 `1.0.0+1`, versionName·versionCode 규칙)
3. ODbL 재배포 조건 법적 확인 (공개 전 필수): 데이터 팩 배포가 파생물 공개 의무에 해당하는지
4. OSM 출처 표기 방식 결정 (스토어 설명 또는 앱 내 라이선스 화면)
5. TTS 음성 미설치 안내 문구 확정 (현재 "오프라인 한국어 음성이 없어 음성 안내는 생략됩니다.")
6. 초안 릴리스 `pack-sample-2026.11`(샘플·테스트용) 공개 전환 여부 결정
7. 전국 팩 빌드 후 CDN 업로드와 배포 URL 등록 (현재 샘플 팩만 있음)

## 완료 확인 (AUTO-OK)

- applicationId·namespace `kr.mukmuk.navi`, 표시 이름 `묵묵`, 아이콘 5개 밀도 교체
- release 서명 연결, `key.properties` 저장소 밖 제외, 릴리스 APK 서명이 업로드 키와 일치
- release APK 생성(arm64·armeabi·x86_64 `.so` 포함), 테스트 32건 통과
- TTS 설치 안내 구현·테스트 완료, OSM 앱 내 표기 있음
- 샘플 팩 무결성(zip 내부 manifest와 일치), 초안 릴리스 존재

- 팩 버전 2026.11, 포맷 1, 원본 OSM 2026-11-02, NGII 미사용

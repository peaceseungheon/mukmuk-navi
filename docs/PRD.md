# 오프라인 로컬 내비게이션 '묵묵(MukMuk)' PRD (Product Requirements Document)

## 1. 프로젝트 개요
* **제품명:** 묵묵 (MukMuk) - "데이터 없이도 묵묵히 길을 엽니다"
* **제품 비전:** 네트워크가 완전히 차단된 극한의 환경이나 저사양 기기에서도 메모리 누수나 프레임 드랍 없이, 빠르고 안정적인 길 안내를 제공하는 100% 오프라인 한국 전용 내비게이션.
* **타겟 사용자:**
  * 네트워크 음영 지역(산간 오지, 오프로드, 캠핑장 등)을 자주 주행하는 운전자
  * 저사양/구형 공기계를 차량에 거치하여 내비게이션 전용으로 사용하는 사용자
  * 데이터 보안이 중요하거나 망 분리가 필요한 특수 목적 차량 운전자 (국방, 재난 대응 등)

## 3. 시스템 아키텍처 및 기술 스택
프론트엔드와 무거운 연산을 분리하는 모던 모바일 아키텍처를 적용하여 앱의 안정성을 극대화합니다.

* **프론트엔드 (UI/UX):** `Flutter` (iOS 및 Android 멀티 플랫폼 대응, 사용자 인터페이스 제공)
* **FFI 바인딩:** `flutter_rust_bridge` (Flutter와 Rust 코어 간 비동기 통신 및 메모리 안전성 보장)
* **코어 엔진 (Core Logic):** `Rust` (경로 탐색, 맵 매칭, TBT 상태 머신 등 고부하 연산 전담)
* **지도 렌더링:** `MapLibre GL Native` (벡터 타일 렌더링 엔진, UI 스레드 최적화)
* **데이터베이스:** `SQLite (FTS5)` (장소, 지번, 도로명 검색용 내장 DB)

## 4. Rust 코어 엔진 설계 및 메모리 최적화 지침
오프라인 내비게이션의 최대 병목인 제한된 모바일 메모리(RAM) 문제를 Rust를 통해 해결합니다.

1. **Zero-Copy 역직렬화:** 라우팅 그래프 파일(수백 MB)을 메모리에 전부 적재(Allocate)하지 않고, `rkyv` 등의 크레이트와 OS의 `mmap`을 결합하여 디스크 데이터를 포인터 캐스팅으로 즉시 읽어 들입니다.
2. **스레드 풀 분리:** GPS 좌표 수신에 따른 맵 매칭과 경로 재계산 연산은 Rust 내부 백그라운드 워커 스레드에서 처리하여 Dart(Flutter) 측의 UI 스레드 버벅임(Jank)을 원천 차단합니다.
3. **예측 가능한 메모리 상한선 적용:** Rust의 소유권(Ownership) 모델을 통해 연산이 끝나는 즉시 할당된 힙 메모리를 해제합니다. 앱 구동 내내 코어 엔진의 RAM 점유율을 엄격히 제어하여 OS의 강제 종료(OOM Kill)를 방지합니다.

## 5. 데이터 구축 파이프라인 (Data Pipeline)
서버 통신 없이 작동하므로, 앱에 탑재할 데이터를 가공하는 강력한 사전 파이프라인이 필요합니다.

1. **데이터 추출:** OpenStreetMap(OSM) 한국 데이터 및 국토지리정보원 수치지도 원본 데이터 확보.
2. **그래프 컴파일 (Rust 빌드용):** 원본 데이터를 Rust 라우팅 엔진이 즉시 읽을 수 있는 최적화된 바이너리 포맷으로 변환.
3. **타일 및 DB 생성:** Mapbox Vector Tile(`.mbtiles`) 파일 생성 및 POI 검색용 SQLite DB 구축.
4. **패키징:** `mbtiles`, `라우팅 바이너리`, `sqlite` 파일을 하나의 패키지로 압축하여 CDN 호스팅.

## 6. 핵심 성공 지표 (KPIs)

* **메모리 최적화 (Memory Footprint):** 경로 탐색 및 주행 중 앱의 총 메모리(RAM) 사용량을 **150MB 이하**로 상시 유지. 장시간(4시간 이상) 모의 주행 시 메모리 누수 0%.
* **경로 재탐색 시간 (Rerouting Latency):** 경로 이탈 인지 후 **1초 이내**에 백그라운드에서 새로운 경로 계산 완료.
* **UI 반응성 (Jank-free):** 지도 이동/확대 및 주행 중 프레임 드랍률 1% 미만 유지 (초당 60fps 방어).
* **검색 응답 속도:** 오프라인 상태에서 반경 50km 이내 장소 검색 시 **0.5초 이내** 결과 반환.

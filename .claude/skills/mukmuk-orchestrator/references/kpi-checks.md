# KPI 측정 방법 (navi-qa용)

에이전트 환경에서 측정할 수 없으면 `MANUAL`로 표시하고 사용자 실행 명령을 적는다. 측정하지 않은 값은 통과로 쓰지 않는다.

| KPI (PRD 6장) | 목표 | 에이전트가 할 일 | 측정 방법 |
| --- | --- | --- | --- |
| 메모리 | 150MB 이하, 누수 0% | 코어 벤치 하네스(`cargo bench`/통합 테스트)에서 샘플 그래프 경로 탐색 반복 후 RSS 증가 추이 기록 | 호스트 RSS는 AUTO 가능. 실기기 총 RAM·4시간 모의 주행은 `MANUAL` (`adb shell dumpsys meminfo <pkg>`) |
| 재탐색 | 1초 이내 | 샘플 그래프에서 이탈 → 재계산 시간을 테스트로 측정(여러 번, 최댓값 기록) | 호스트 AUTO. 실기기는 `MANUAL` |
| 프레임 | 드랍 1% 미만 | 정적 확인: 무거운 연산이 Dart에 없는지, 위치 갱신 위젯 범위 | 실측은 `MANUAL` (`flutter run --profile` + DevTools) |
| 검색 | 반경 50km, 0.5초 | 샘플 sqlite로 FTS5 쿼리 시간 측정 | 샘플 규모는 AUTO. 전국 데이터는 `MANUAL` |

샘플 데이터 결과는 전국 데이터 성능을 보장하지 않는다. `verify.md`에 샘플 규모를 같이 적는다.
